좋아하는 오프닝

Before는 시작 배치, After는 아래 기본 수순을 둔 뒤의 배치입니다. 각 체스판의 버튼을 눌러 비교해 보세요.

체스판은 백의 시점입니다. 수순 길이는 백과 흑의 착수를 각각 한 번으로 세며, 두 정렬 버튼은 병합 정렬을 사용합니다.

정렬은 어떻게 다를까?

오프닝 정보를 배열에 담고, 병합 정렬로 수순 길이 또는 영문 제목에 따라 정렬했습니다. 배열을 절반으로 나누어 정렬한 다음, 앞쪽 값부터 비교하며 합치는 방식입니다.

병합 정렬과 삽입 정렬
비교 항목병합 정렬삽입 정렬
최선 시간O(n log n)O(n)
평균·최악 시간O(n log n)O(n²)
정렬 본체의 추가 공간O(n)제자리 구현 O(1)

동일한 역순 정수 1,024개를 정렬하며 비교 함수 호출 횟수를 셉니다. 특정 입력에서의 비교 횟수이며 실행 시간은 아닙니다. 비교용 구현은 원본 보존을 위해 입력 배열의 사본을 사용합니다.

버튼을 누르면 두 알고리즘의 비교 결과가 표시됩니다.

삽입 정렬은 이미 정렬된 작은 배열에서 효율적입니다. 병합 정렬은 입력 순서에 관계없이 O(n log n) 시간에 정렬합니다.
